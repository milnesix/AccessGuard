# AccessGuard

**AccessGuard** is an access control system developed in C++ using SFML.

The project was created as the final project for the second-semester course
**Programowanie strukturalne i obiektowe (Structural and Object-Oriented Programming)**
in the **Automatyka i Robotyka (Automatic Control and Robotics)** degree program
at Poznań University of Technology.

The degree program is taught in Polish, and the application interface and project documentation are also in Polish.

## Technologies

- C++17
- SFML 3.1.0
